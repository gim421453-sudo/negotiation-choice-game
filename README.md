# 협상의 선택

『협상의 기술 1』을 읽고 협상 상황을 직접 선택하며 체험하도록 만든 **학교 독서 후속 활동용 웹게임**입니다.

상대방의 요구를 그대로 받아들이거나 일방적으로 거절하는 대신, **왜 필요한지 질문하고 마감을 확인하며 함께 이익을 얻는 대안**을 생각해 보는 것이 목적입니다. 게임 속 상황, 대화, 수치는 학습을 위해 구성한 가상 사례이며 책의 문장을 그대로 재현한 것은 아닙니다.

## 🕹 플레이 방법

1. 시작 화면에서 시나리오를 선택합니다.
2. 상대방의 제안을 읽고 **내가 말할 선택지**를 직접 누릅니다.
3. 상대방의 답변을 확인하고 다음 행동을 결정합니다.
4. 정보 확인 → 시간 압박 판단 → 최종 합의 제안의 순서로 진행합니다.
5. 최종 결과에서 **윈윈 합의 / 일방적 합의 / 협상 결렬**, 신뢰도, 준비 시간, **양쪽 팀의 만족도 비교와 결말별 상세 해설**, 선택 기록과 교훈을 확인합니다.
6. **다시 시작**을 누르면 다른 시나리오도 체험할 수 있습니다. 진행 중에도 화면 위쪽의 **🏠 처음으로** 버튼으로 시나리오 선택 화면에 돌아갈 수 있으며, 진행 상황이 초기화되기 전에 확인창이 나타납니다.

사용자가 선택하지 않은 플레이어 대사는 자동으로 출력되지 않습니다.

## ⚖️ 점수의 의미

- **신뢰도**: 질문, 협조 또는 일방적 요구에 따른 관계 변화를 나타내는 게임 점수입니다.
- **준비 시간**: 협상 선택에 따라 남을 것으로 예상되는 시간입니다. 합의가 끝나기 전까지는 예상값으로 표시됩니다.
- 높은 준비 시간만으로 반드시 좋은 협상은 아닙니다. **상대방의 만족과 신뢰**도 결말에 영향을 줍니다.

> 신뢰도와 시간 변화는 실제 협상 연구의 통계나 객관적 평가값이 아닌, 선택의 결과를 비교하기 위한 **학습용 가상 수치**입니다. 결말의 양쪽 팀 만족도도 실제 설문이나 심리 측정값이 아닌 게임 내부의 예시 평가(각 1~5점)입니다.

## 🛠 기술 및 구조

- **HTML · CSS · Vanilla JavaScript**
- 서버, 데이터베이스, 로그인, 유료 API 없이 동작
- 결말 수집 기록은 사용 중인 기기의 브라우저(`localStorage`)에만 저장되며 서버로 전송되지 않습니다.
- 휴대전화, 태블릿, PC 화면에 대응하는 반응형 레이아웃

```text
index.html  # 기본 화면
style.css   # 화면 스타일 및 반응형 디자인
script.js   # 시나리오, 대화 분기, 점수, 결말
README.md   # 프로젝트 안내
협상의선택_사용설명서_v1.2.pdf  # 사용설명서
협상의선택_README.pdf          # README의 PDF 버전
```

로컬에서 실행하려면 저장소 파일을 같은 폴더에 두고 `index.html`을 웹브라우저에서 엽니다. 모바일에서는 로컬 파일 열기가 제한될 수 있어 웹 배포 주소 이용을 권장합니다.

## ✅ 현재 구현 범위

- 6개 시나리오 선택 (기존 행사 준비 3개 + 모둠 발표·자습 공간·체육관 3개)
- 단계별 선택에 따른 플레이어 발언 → 상대 응답 → 후속 선택지
- 신뢰도·준비 시간 계산
- 3종 결말, **양쪽 팀 만족도 비교**, 결말별 4문장 해설 및 선택 기록
- 다시 시작 기능
- 시작 화면의 접을 수 있는 **게임 방법·점수 설명** (처음 접속할 때만 펼쳐짐)
- 진행 중 **처음으로 돌아가기** 버튼 (진행 상황 초기화 전 확인창)
- 시나리오별 **결말 수집 현황** 표시(6개 시나리오 × 3종 결말)와 기록 초기화
- 반응형 화면 및 대화 스크롤 보정
- **사용설명서 PDF**와 README PDF 제공
