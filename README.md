# 협상의 선택

『협상의 기술 1』을 읽고 협상 상황을 직접 선택하며 체험하도록 만든 **학교 독서 후속 활동용 웹게임**입니다.

상대방의 요구를 그대로 받아들이거나 일방적으로 거절하는 대신, **왜 필요한지 질문하고 마감을 확인하며 함께 이익을 얻는 대안**을 생각해 보는 것이 목적입니다. 게임 속 상황, 대화, 수치는 학습을 위해 구성한 가상 사례이며 책의 문장을 그대로 재현한 것은 아닙니다.

## 🎮 게임 실행

**[웹게임 플레이하기](https://gim421453-sudo.github.io/negotiation-choice-game/)**

별도의 계정이나 설치 없이 웹브라우저에서 실행하는 정적 웹게임입니다. GitHub Pages가 정상적으로 설정되어 있어야 위 주소에서 열립니다.

## 🧩 시나리오

| 시나리오 | 갈등 상황 | 학습 포인트 |
| --- | --- | --- |
| 🏫 교실 사용 시간 협상 | 부스 운영팀과 공연 준비팀이 한 교실을 사용하려 함 | 겉으로 드러난 요구와 실제 필요 구분 |
| 🎤 방송 장비 사용 시간 협상 | 영상팀과 진행팀이 방송 장비 사용 시간을 조정해야 함 | 제한된 자원의 공동 사용 |
| 🙋 행사 준비 인력 협상 | 장식팀과 안내팀이 인력 지원 시간을 조정해야 함 | 서로 도움을 주고받는 대안 |

## 🕹 플레이 방법

1. 시작 화면에서 시나리오를 선택합니다.
2. 상대방의 제안을 읽고 **내가 말할 선택지**를 직접 누릅니다.
3. 상대방의 답변을 확인하고 다음 행동을 결정합니다.
4. 정보 확인 → 시간 압박 판단 → 최종 합의 제안의 순서로 진행합니다.
5. 최종 결과에서 **윈윈 합의 / 일방적 합의 / 협상 결렬**, 신뢰도, 준비 시간, 선택 기록과 교훈을 확인합니다.
6. **다시 시작**을 누르면 다른 시나리오도 체험할 수 있습니다.

사용자가 선택하지 않은 플레이어 대사는 자동으로 출력되지 않습니다.

## ⚖️ 점수의 의미

- **신뢰도**: 질문, 협조 또는 일방적 요구에 따른 관계 변화를 나타내는 게임 점수입니다.
- **준비 시간**: 협상 선택에 따라 남을 것으로 예상되는 시간입니다. 합의가 끝나기 전까지는 예상값으로 표시됩니다.
- 높은 준비 시간만으로 반드시 좋은 협상은 아닙니다. **상대방의 만족과 신뢰**도 결말에 영향을 줍니다.

> 신뢰도와 시간 변화는 실제 협상 연구의 통계나 객관적 평가값이 아닌, 선택의 결과를 비교하기 위한 **학습용 가상 수치**입니다.

## 🛠 기술 및 구조

- **HTML · CSS · Vanilla JavaScript**
- 서버, 데이터베이스, 로그인, 유료 API 없이 동작
- 휴대전화, 태블릿, PC 화면에 대응하는 반응형 레이아웃

```text
index.html  # 기본 화면
style.css   # 화면 스타일 및 반응형 디자인
script.js   # 시나리오, 대화 분기, 점수, 결말
README.md   # 프로젝트 안내
```

로컬에서 실행하려면 저장소 파일을 같은 폴더에 두고 `index.html`을 웹브라우저에서 엽니다. 모바일에서는 로컬 파일 열기가 제한될 수 있어 웹 배포 주소 이용을 권장합니다.

- 신뢰도·준비 시간 계산
- 3종 결말 및 선택 기록

- 반응형 화면 및 대화 스크롤 보정

## 📚 제작 배경

허브 코헨의 『협상의 기술 1』을 읽은 뒤, 책에서 접한 협상에 관한 생각을 **학급 행사 준비라는 가상 상황**에 적용해 보기 위해 기획했습니다. 선택한 대응 방식에 따라 서로의 이익과 관계가 어떻게 달라지는지 비교해 볼 수 있습니다.
